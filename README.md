# Welcome to my Personal Portfolio

I decided to go with a desktop-esque approach with a taskbar, floating windows and *folders* that are shown like desktop windows.

## Widgets
The current "widgets" I have on the home screen:
- **Last Played/Now Playing**: Connected to Spotify for Now Playing and Youtube Music for Last Played.
- **Personal Information**: It reads the data in `profile.js` and displays it as personal information, including social through icons
- **Steam Last Played**: Connected to Steam API to fetch the last played game in Steam
- **Black List(?)**: *coming soon*

## Interests
 contains categories that I have interest in such as:
- Coding
    - connected to Github to fetch my public repositories.
- Kpop
    - connected to Spotify and Youtube Music to fetch my most/recently played music per artist and (past) year.
- Games
    - connected to Steam to list my games by total hours played.
- Sports
    - contains logs, information and galleries for sports I have taken interests in.
